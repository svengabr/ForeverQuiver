# AGENTS.md

Notes for AI agents working on Forever Quiver.

## What the addon does

A port in spirit of Quiver (Turtle WoW hunter addon, AGPL, github.com/SabineWren/Quiver) to WoW: Forever, plus
extra features a guild member asked for (spell menus on one key, ammo warning, beast ability tooltip, smaller
Auto Shot bar, Questie arrow). Written from scratch; do not paste Quiver code (license differs).

- `Core.lua` – namespace (`ForeverQuiver` global = `ns`), defaults, `ns.MakeMovable`, spell helpers, slash command.
- `Locale.lua` – English keys, deDE overrides.
- `Modules/*.lua` – one module each, registered with `ns.RegisterModule(name, { Init, Refresh })`.
  `Init` runs on PLAYER_LOGIN, `Refresh` after any option change.
- `BeastData.lua` – generated by `tools/gen_beast.js` from AllTheThings'
  `.contrib/.db/forever/character/hunter/beast training.lua`. Do not edit by hand.
- `UI/` – options window: `OptionSections.lua` is the data (sections, controls), `OptionsWindow.lua` draws it,
  `Style.lua` the look (same as the maintainer's KeepOrSell).
- `Shots.lua` – `/fq shots`: gallery screenshots. It freezes the simulation through `ns.demoFreeze`; a module's
  simulation branch must read time from `ns.DemoClock(key)` and the player's name from `ns.DemoName()`, never
  `GetTime()` or the real name, or the pictures differ from run to run. Secure frames are left alone.
- `Modules/Flyout.lua` – secure buttons. Anything that touches them must run out of combat; `Rebuild` defers
  to PLAYER_REGEN_ENABLED. Buttons register only for the click type matching `ActionButtonUseKeyDown`.
- `Modules/Navigator.lua` – defines a minimal global `TomTom` (AddWaypoint/RemoveWaypoint) only when TomTom is not
  going to load, so Questie's TomTom hooks drive the arrow.

## Artwork

`media/logo.svg` is the source of the logo (a quiver on the teal medallion, in the look of the maintainer's other
addons). `sh media/render-logo.sh` renders `media/logo.png` (512×512, the CurseForge logo) and `Icon.tga` (64×64,
the addon list icon named in the TOC). `docs/curseforge.md` holds the texts for the CurseForge project page; its
description is the README without the title and logo.

## Client facts

- Interface 16001, Blizzard UI source: Gethe/wow-ui-source, branch `forever` (a 12.x-based client).
- Secret restrictions are active on Forever (seen in the client: `GetUnitSpeed` returns a secret). Never compare
  or do maths on an API value without `ns.Plain`/`ns.IsSecret`. Movement comes from PLAYER_STARTED/STOPPED_MOVING. The combat log is only used when
  `C_Secrets.HasSecretRestrictions()` is false.
- Auto Shot fires `UNIT_SPELLCAST_SUCCEEDED` with spell 75.

## Rules

- English only in the repo (code, comments, commits, docs).
- Conventional Commits.
- No unit tests; in-game behaviour can only be checked in the client – say so honestly.
- luacheck: `docker run --rm -v "$PWD:/data" -w /data ghcr.io/lunarmodules/luacheck .` – add new globals to
  `.luacheckrc`.
