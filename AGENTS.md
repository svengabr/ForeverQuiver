# AGENTS.md

Notes for AI agents working on Forever Quiver.

## What the addon does

A port in spirit of Quiver (Turtle WoW hunter addon, AGPL, github.com/SabineWren/Quiver) to WoW: Forever, plus
extra features a guild member asked for (spell menus on one key, ammo warning, beast ability tooltip, smaller
Auto Shot bar, Questie arrow). Written from scratch; do not paste Quiver code (license differs).

- `Core.lua` – namespace (`ForeverQuiver` global = `ns`), defaults, `ns.MakeMovable`, spell helpers, slash command.
- `Locale.lua` – English keys, deDE overrides.
- `Modules/*.lua` – one module each, registered with `ns.RegisterModule(name, { Init, Refresh })`.
  `Init` runs on PLAYER_LOGIN, `Refresh` after any option change.
- `BeastData.lua` – generated by `tools/gen_beast.js` from AllTheThings'
  `.contrib/.db/forever/character/hunter/beast training.lua`. Do not edit by hand.
- `Modules/Flyout.lua` – secure buttons. Anything that touches them must run out of combat; `Rebuild` defers
  to PLAYER_REGEN_ENABLED. Buttons register only for the click type matching `ActionButtonUseKeyDown`.
- `Modules/Navigator.lua` – defines a minimal global `TomTom` (AddWaypoint/RemoveWaypoint) only when TomTom is not
  going to load, so Questie's TomTom hooks drive the arrow.

## Client facts

- Interface 16001, Blizzard UI source: Gethe/wow-ui-source, branch `forever` (a 12.x-based client).
- Many unit/spell APIs can return secret values; guard with `ns.IsSecret`. The combat log is only used when
  `C_Secrets.HasSecretRestrictions()` is false.
- Auto Shot fires `UNIT_SPELLCAST_SUCCEEDED` with spell 75.
